# The import folder

Put a dex (`dex_<study>_<time>.tar.zst`, or its unpacked folder) or a study bundle here. A dex is read in by itself
within a minute of being put here, and at a study's start if it is here before the first `main.py run`: in a study
designed to verify a dex first (178), its laws become their own campaign, each run again to N=4,096 (or the dex's own
level) and checked chain by chain against the dex before anything else runs. A study bundle is read in once ticked and
synchronized on the Map page. Nothing in this folder is changed or deleted; the dex a folder writes goes to `export/`.
