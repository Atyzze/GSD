build's notes, and this history as it stood then, are in that build's archive (`GSD<N>.tar.zst`); what the data
settled is `docs/RESEARCH_METHOD.md`, the rules the builds taught `docs/LESSONS.md`.

## What the programme set out to do

The question is `docs/WHERE_WE_ARE.md`, "The question" (the operator, 2026-10-13 18:20). The loop the operator set out
on 2026-09-25: breadth, every outlier remembered; known patterns retired; the literature's terms reproduced with the
same instrument; new terms chosen from that vantage; the map opened to the public. On 2026-10-01 they added the null
atlas as the baseline every stage is measured against ("so we can see the atlas move as we add new/more terms"), and
on 2026-10-07 the end state: the null map, then one or two terms added and the map compared ("then that is our end
state because I do want to wrap this up").
